Running in Docker

Raddy is serving! 🚀

Your high-performance, memory-safe Rust web server and reverse proxy is up and running in a container.

How to customize your configuration
docker run -d \
  -p 80:80 -p 443:443 -p 443:443/udp \
  -v $(pwd)/Caddyfile:/etc/caddy/Caddyfile:ro \
  -v raddy_data:/data \
  ghcr.io/fokx/raddy:latest
Or serve a local folder
docker run -d \
  -p 8080:80 \
  -v $(pwd)/my-site:/usr/share/caddy:ro \
  ghcr.io/fokx/raddy:latest
